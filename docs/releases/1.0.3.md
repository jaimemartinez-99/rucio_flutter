Consultas de lectura con búsqueda local: Rucio selecciona pasajes relevantes del texto ya leído y los envía a Claude, reduciendo el tamaño y el coste de las preguntas.

El modo económico usa Haiku. El panel muestra una estimación antes de enviar, el consumo real de tokens y el coste de cada respuesta. Puedes desplegar los pasajes utilizados y consultar sus referencias.

Se conserva el límite exacto de lectura para excluir texto posterior. Claude recibe el capítulo y el porcentaje actuales, y distingue la falta de evidencia recuperada de un acontecimiento que todavía no se haya leído.

Disponible en Android y Windows. No requiere configurar servicios nuevos ni ejecutar un modelo de IA en el dispositivo.
